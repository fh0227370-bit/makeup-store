# متجر لمسة — دليل التعديل والتجربة

هذه صفحة متجر ثابتة باللغة العربية، تعمل على الهاتف والكمبيوتر. بيانات المتجر والمنتجات مفصولة عن التصميم حتى تتمكني من تحديثها بسهولة.

## تجربة الصفحة

افتحي `index.html` في المتصفح لمعاينة المتجر. للحصول على أفضل نتيجة، ارفعي المستودع إلى GitHub وفعّلي GitHub Pages من **Settings → Pages** باختيار الفرع `main` ومجلد الجذر `/`، ثم افتحي رابط الموقع الذي يظهر لك في صفحة Pages.

## تعديل بيانات المتجر والمنتجات

افتحي الملف `store-data.js` واضغطي على القلم **Edit** في GitHub. عدّلي القيم المطلوبة ثم اضغطي **Commit changes**. بعد حفظ التعديل، يعرض الموقع المحتوى الجديد تلقائياً.

- **اسم المتجر والشعار:** `storeName` و`tagline`.
- **رقم واتساب لاستقبال الطلبات:** `whatsappNumber`؛ اكتبيه بصيغة دولية أرقام فقط، من دون `+` أو مسافات، مثل `9665xxxxxxxx` للسعودية. اتركيه فارغاً إلى أن تجهزي رقم المتجر.
- **النصوص والصور الرئيسية:** `announcement` و`hero` و`story`.
- **العملة والبريد:** `currency` و`email`.
- **الروابط الاجتماعية:** ضعي رابط الحساب مكان القيمة الفارغة في `socials`.
- **المنتجات:** كل منتج داخل مصفوفة `products` وله `id` فريد واسم وفئة ووصف وسعر وصورة. لإضافة منتج، انسخي سطراً كاملاً داخل المصفوفة وغيّري البيانات، واستخدمي رقماً جديداً في `id`.
- **صور المنتجات:** بإمكانك وضع رابط صورة كامل، أو رفع الصورة إلى مجلد `images` في المستودع ثم كتابة مسار مثل `images/lipstick.jpg`. بعد رفع صورة، حدّثي قيمة `image` للمنتج. الصور التي تستخدمينها يجب أن تكون مملوكة لكِ أو مرخصة للاستخدام.
- **الفئات:** معرّفات الفئات الحالية هي `face` و`lips` و`eyes` و`care`. أضيفي أي فئة جديدة إلى `categories` واستخدمي معرّفها نفسه في المنتج.
- **الخصم:** أضيفي `oldPrice` إلى المنتج لإظهار السعر السابق.

## ملاحظات قبل استقبال طلبات حقيقية

السلة تحفظ محتوياتها في المتصفح، وزر الطلب يجهز تفاصيل السلة ويرسلها إلى واتساب. هذه النسخة لا تعالج الدفع الإلكتروني أو إدارة المخزون أو حفظ الطلبات في قاعدة بيانات؛ يلزم إعداد خدمة متجر/دفع عند الحاجة إليها. نموذج الاشتراك الحالي تجريبي ولا يحفظ عناوين البريد الإلكتروني.

لتغيير التصميم أو إضافة خصائص بعد التجربة، عدّلي `index.html` أو اطلبي الإضافة المطلوبة. ملفات البيانات والتصميم منفصلة لتسهيل التحديثات.
